# JAL-RAKSHAK Frontend

A frontend-only hackathon demo for the JAL-RAKSHAK smart flood early-warning system.

## Deployment

This version intentionally has **zero npm dependencies** and no build step, so it can be deployed directly to Vercel.

Upload the project folder to Vercel Drop, or import it into a Git repository. Vercel will serve `index.html` directly.

## Demo routes

- `/login`
- `/`
- `/current`
- `/analytics`
- `/events`
- `/assistant`
- `/devices`
- `/risk-prediction`

The UI uses realistic mock sensor data and is ready to connect to a REST backend later.
