# JAL-RAKSHAK Firestore Collections

## 1. sensors

Stores incoming sensor readings.

Example:

{
  "deviceId": "ESP32-001",
  "timestamp": "2026-09-06T10:30:00.000Z",
  "waterLevel": 72.5,
  "rainfall": 18.4,
  "temperature": 29.2,
  "riseRate": 1.8,
  "acceleration": 0.35,
  "waterTrend": "RISING",
  "sensorQuality": 98,
  "latitude": 12.9716,
  "longitude": 77.5946,
  "riskScore": 64,
  "status": "WARNING"
}

---

## 2. events

Stores detected water-risk events.

Event types:

- FLOOD_ESCALATION
- ABNORMAL_WATER_LOSS
- SENSOR_ANOMALY
- NORMAL

---

## 3. devices

Stores registered ESP32 monitoring devices.

Example:

{
  "deviceId": "ESP32-001",
  "name": "River Monitor 01",
  "location": "Chennai",
  "latitude": 13.0827,
  "longitude": 80.2707,
  "status": "ONLINE",
  "lastHeartbeat": "2026-09-06T10:30:00.000Z"
}

---

## 4. alerts

Stores alerts generated by the risk engine.

Example:

{
  "deviceId": "ESP32-001",
  "type": "FLOOD_ESCALATION",
  "severity": "CRITICAL",
  "riskScore": 91,
  "message": "Flood risk detected",
  "status": "ACTIVE",
  "createdAt": "2026-09-06T10:30:00.000Z"
}

---

## 5. users

Stores application users.

Example:

{
  "name": "Admin",
  "email": "admin@jalrakshak.com",
  "role": "ADMIN",
  "createdAt": "2026-09-06T10:30:00.000Z"
}
